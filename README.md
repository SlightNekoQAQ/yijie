# 弈界 Yijie

中国象棋与国际象棋，在同一张棋盘上相遇。

弈界是一款完全离线的 Android 棋类游戏。选择九路中国象棋棋盘或八路国际象棋棋盘，双方可以独立选择中式或西式走法：既能进行同规则对局，也能尝试两种棋制之间的混合对战。

## 下载安装

前往 **[最新正式版](https://github.com/SlightNekoQAQ/yijie/releases/latest)**，下载 `yijie-0.3.0.apk` 并在 Android 手机上安装。

- 支持 Android 7.0 及以上。
- 无需账号，无需联网，棋局保存在本机。
- 系统可能需要允许浏览器或文件管理器安装来自此来源的应用。
- 0.2.0 及之后的版本可覆盖更新。0.1.0 若提示签名冲突，需要先卸载；卸载会清除本地棋局。

## 对局方式

**同机双人**：双方都选择玩家。对坐时，各自棋子的朝向面向自己，也可以随时翻转棋盘。

**人机对弈**：任意一方交给本地 AI，练习不同阵容与走法。

**AI 观战**：双方都选择 AI，观看两套棋制交锋；可暂停或随时接手。

支持悔棋、升变选择、走棋记录、自动存档、落子动画与可关闭的音效。选中棋子会显示合法落点；无法移动时，会提示阻挡、走法或解将原因。

## 棋盘与规则

九路棋盘上的中式方保留车、马、象、士、将、炮、兵。西式方使用国际象棋走法，并提供让车、撤后及单后三种实验阵容。八路棋盘上的西式方使用标准国际象棋阵容，中式方使用适配该棋盘的实验阵容。

中式棋子遵循九宫、河界、马腿、象眼、炮架及兵过河限制。西式兵支持首步两格、斜吃、吃过路兵与升变；王车易位仅在八路棋盘且双方都采用西式走法时开放。

**本游戏的统一胜负约定：**不能暴露己方王或将；无合法着的一方判负，即使没有受到将军；三次重复局面判和。因此西式对局的逼和判定与标准国际象棋不同。暂未实现中国象棋中的长将、长捉裁决。

走法参考 [FIDE 国际象棋规则](https://handbook.fide.com/chapter/E012023)及[世界象棋联合会规则](https://www.wxf-xiangqi.org/index.php?option=com_content&view=article&id=271&Itemid=290&lang=cn)。混合阵容、八路中式九宫与跨棋制攻击关系属于弈界自定玩法，并非官方赛事规则。

## 关于 AI 与混合玩法

AI 完全在设备上运行，按双方各自棋制评估材料、位置和将军，残局会尝试更深搜索。它适合休闲试玩，但不是专业棋力引擎，仍可能漏掉长杀或在残局反复走动。

混合玩法尚在探索，**不保证双方阵容公平**。默认让车方案用于减轻西式方优势，其他阵容可用于对照体验。正式版表示提供固定签名的 release 安装包，并不表示实验规则已经定型。
