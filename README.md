# 弈界 (Yijie)

完全离线的 Android 混合象棋实验版。一个棋盘决定双方的初始位置，两名玩家分别选择中国象棋或国际象棋走法；每一方在局内可独立切换真人或 AI。支持双人同机、单人对 AI、AI 对 AI 观战、暂停、悔棋、翻转、走棋记录和本地自动存档。

## 安装包构建

将**本目录内容**作为 GitHub 仓库根目录推送，在 Actions 中运行 `Android APK`，从运行页面的 `yijie-debug-apk` 下载 `app-debug.apk`。`push` 到 `main` 也会触发构建。该 APK 是可直接侧载的 debug 安装包，尚未配置正式发布签名。Actions 使用 JDK 17、Gradle 8.10.2、Android SDK 35；不需要在手机本地安装 Android SDK，也无需在工作流里配置私人 token。

本机有 Node.js 时，运行 `node --test tests/*.test.js` 检验规则。

## 第一版规则

- 中式棋盘为 9×10 交点；西式棋盘为 8×8 格。双方使用该棋盘对应的初始位置，再由各自走法决定棋子映射。
- 9×10：中式方为标准车马象士将炮兵。西式方将原有马、车映射为国际象棋马、车；象映射为西式象；将映射为王；两枚炮撤掉，一枚士留空，原 c 路的象位改放西式后，d 路的士位改放西式象，另一象位也改为西式象；五枚兵留在原位但按西式兵走法。这一调换是为了避免后从 d 路开局直攻九宫形成速胜。
- 8×8：西式方为标准国际象棋阵容。中式方的车、马、象、王、兵分别映射为车、马、象、将、兵；后的位置是一个士，没有炮。这是独立实验预设，并非标准中国象棋阵容。
- 中式将/士局限九宫，中式象不能过河，马蹩腿，象塞象眼，炮隔一子吃，兵过河可以横走。8×8 中式九宫是居中的四列 × 三行；河界在两方中间。
- 西式兵首步可走两格、斜吃、吃过路兵，到底线可选后/车/象/马升变。仅双方均按西式规则且在 8×8 棋盘上可以王车易位。
- 走棋不能使自己的王/将被攻击；将死判胜。无合法走法即使未被将军也判负。王/将不可直接被吃。三次重复局面判和。
- 相同棋盘不同走法及中式走法落在西式棋盘上均为实验规则。混合玩法尚无可靠平衡性数据。

## AI 状态

当前 AI 是共享规则判定器之上的本地两层搜索，用于使三种对局形式可玩；它**不是**皮卡鱼或 Stockfish，棋力较弱，复杂局面下可能短暂卡顿。后续计划在标准局分别接入 Pikafish 与 Stockfish 的离线 Android 二进制，并在混合局升级共享搜索与局面评估。引擎接入时需要同时核对授权、源码提供和架构兼容性；现有 APK 不包含这些外部引擎或网络功能。

## 目录

- `app/src/main/assets/rules.js`：共用走法、胜负判定、基础 AI
- `app/src/main/assets/app.js`、`style.css`、`index.html`：离线对局界面
- `app/src/main/java/com/yijie/game/MainActivity.java`：Android WebView 容器
- `tests/rules.test.js`：规则回归测试
- `.github/workflows/android.yml`：CI 构建并上传 APK
